      Classes & hand-ins

      Where does my work go?

      Guest drafts are saved in this browser when local storage is available. Signed-in students can sync private drafts across devices. JavaScript execution still happens in the browser; it does not run on a paid server.

      Saving or marking work finished does not submit it. A signed-in student can join an approved class and use Submit work to turn in a separate dated copy.

      Before you leave: use Download to save an individual code file or Back up work to save all your drafts. You can restore a backup later with Import backup.

      Teachers can view explicitly submitted copies, not private drafts. Sign out on shared devices. GitHub repository permissions are not required to sign in.
